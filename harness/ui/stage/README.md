## 🎨 描くときに開くフォルダ

| 目的 | 場所 | 何を置くか |
|---|---|---|
| **上に描く元** | `%USERPROFILE%\Pictures\AIart\_inbox\` | 生成した原画。**リポジトリの外**（原画は git に入れない） |
| **ラフを置く** | `rough\` | 原画の上に描いたポーズの下書き。**自動では読まれない**。`rk-refine.ps1`（img2img）に渡してから取り込む |
| **完成したドットを置く** | `draw\`（椅子に座る）/ `draw-bg\`（部屋）/ `draw-eye\`（目） | もう仕上がった画素。`draw*.cmd` がそのまま取り込む |
| **参考** | `ref\` | 顔と同一性の基準（`belka.ref.png` 328×480）。公開版には入れていない |

### `rough\` と `draw\` の違い

- `draw\` = **モデルを通さない。** 置いた画素がそのまま画面に出る。
- `rough\` = **まだモデルを通していない。** `rk-refine.ps1` に渡して絵にしてから、その結果を取り込む。

⚠ **`rk-refine.ps1` は長辺 640px 未満を拒否する。** SDXL は 1024 前後が前提で、
小さい絵（`art\belka.png` 249×320）に当てたら崩れた（実測）。
**スプライトはパイプラインの出口であって、入口ではない。** ラフは**原画と同じ寸法**で描く。

### 画面全体のラフを描くなら

コンソールのステージは **560×376 を2倍で表示**している（画面上は 1120×752）。
全体のラフは **1120×752** で描けば原寸。パネル右レールは **296×600 を等倍**。

## 今の絵の正本は `.rkspr`

`art\*.rkspr` が**表示されている実体**（テキストの画素マップ。`*` が状態色、`+` はその減光）。
隣の `.png` は同じものを見るための書き出しで、**読まれていない**。

| `art\` の中 | 何 |
|---|---|
| `*.rkspr` | 🔴 **正本。これが画面に出る** |
| `*.png` | 1倍の書き出し（目視用） |
| `_preview\` | 2倍・4倍・6倍の拡大（**何も読んでいない**。目で確かめる用）。公開版には入れていない |
| `_backup\` | 取り込みが手作業の印を上書きする直前に取った控え（`.rkspr.marked`）と旧版。公開版には入れていない |
| `_candidates\` | 2026-08-30 に落選した背景案。**採用されていない**。公開版には入れていない |

## 絵を入れ替える手順

```powershell
powershell -STA -File harness\ui\stage\build-belka.ps1
```

**手で `rk-import-art.ps1` を叩かない。** 取り込みのあとに当てる手作業の編集
（どのパレット番号が状態ランプか、どの矩形が目か）が `build-belka.ps1` に書いてあり、
**再取り込みでは消える**から。両方のツールが「何画素変えたか」を出す。**その数字が確認であって、絵ではない。**

## エヴァが開くのはここではない

絵の作業は **`%USERPROFILE%\Pictures\AIart\ベルカ\`** だけで完結する（[R-099追記2]）。
Pictures と repo を往復させないための移設で、番号つきの日本語フォルダとボタンがそこにある。

| そこ | 何 |
|---|---|
| `0_見本` | 顔と色の基準 |
| `1_元絵` | 描く元5枚（`1_椅子に座る` 896x1152 ほか） |
| `2_ラフ` | 描いたラフの置き場 |
| `3_AI仕上げ` | `rk-rough.ps1` の出力 |
| `ラフをAIに通す*.cmd` | このリポジトリの `rk-rough.ps1` を呼ぶだけの殻。判断を持たない |

**番号だけがスクリプトの手がかり。** `.ps1` も `.cmd` も ASCII 限定なので日本語の名前を書けない。
`rk-rough.ps1` は `2_*` `3_*` という**接頭辞で**フォルダを引く。日本語の部分は改名してよい。

🔴 **ComfyUI の `/upload/image` は日本語のファイル名で 500 を返す**（実測）。
`rk-rough.ps1` は使い捨ての ASCII 名で渡して、結果を日本語名に戻す。ラフ本体は触らない。
