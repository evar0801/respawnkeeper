Put ROUGH sketches here - a pose drawn over one of the originals in
%USERPROFILE%\Pictures\AIart\_inbox\ .

This folder is NOT the importer. Nothing here is read automatically.
A rough goes to rk-refine.ps1 (img2img), which turns it into a finished
picture; only THAT result is imported.

  draw\   = finished pixels, imported as-is by draw*.cmd
  rough\  = a sketch that still has to go through the model

Keep the canvas the same size as the original you drew over. rk-refine.ps1
refuses anything whose long side is under 640 px.
